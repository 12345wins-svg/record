녹화 설정

저장 폴더
선택된 폴더 없음

Chrome은 '문서', '다운로드', '바탕 화면' 같은 시스템 폴더 자체는 선택할 수 없습니다. 그 안에 새 폴더(예: CamRec)를 만든 뒤 선택하세요.

녹화 전 점검 사항

  • https 주소에서 열어야 합니다. 카메라·마이크는 보안 연결에서만 동작합니다. 이 파일을 GitHub Pages, Netlify 등 https로 올려 Chrome으로 여세요(로컬 파일은 권한이 제한될 수 있습니다).
  • 웹페이지는 전화·문자·시스템 알림 팝업을 직접 막을 수 없습니다. 아래 시스템 설정으로 차단하세요.
    ① 비행기 모드 켜기 — 전화·문자 수신 자체가 차단됩니다(이 프로그램은 인터넷이 필요 없음).
    ② 또는 방해 금지 모드를 켜고 예외를 모두 끄기.
    ③ 화면 고정(앱 고정) — 설정 › 보안 및 개인정보 보호 › 기타 보안 설정에서 켠 뒤, 최근 앱 화면에서 Chrome 아이콘 › '이 앱 고정'(메뉴 위치는 기종마다 다릅니다).
  • 녹화 중에는 충전기를 연결하고, 설정 › 배터리에서 Chrome 사용량 제한을 해제하세요. 장시간 녹화는 발열에 주의하세요.
  • 화면이 꺼지거나 Chrome이 백그라운드로 가면 카메라가 중단됩니다. '화면 어둡게'(두 번 탭하면 해제)를 쓰면 화면을 켠 채 전력을 줄일 수 있습니다.
  • Android Chrome은 폴더 직접 지정이 불가능합니다. 브라우저 내부 저장소에 저장하면 아래 목록에서 파일별로 내려받고, 다운로드 폴더 자동 저장은 Chrome 설정 › 다운로드 › 위치에서 저장 위치를 바꿀 수 있습니다.
  • 영상의 시각은 휴대폰 시계 기준입니다. 설정에서 자동 날짜 및 시간을 켜 두세요.

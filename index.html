주소 및 보안 연결 확인 중…

실제 휴대폰에서는 Chrome 주소창이 https://로 시작해야 합니다. 다운로드한 HTML을 휴대폰 파일 앱에서 바로 열면(content:// 주소) 녹화할 수 없습니다.

점검 버튼으로 저장소 쓰기 권한을 미리 확인할 수 있습니다.

영상 및 마이크 설정

음성의 하드웨어 입력 레벨은 웹에서 최대치로 강제할 수 없으며, 녹음 신호에 디지털 증폭을 적용합니다.

영상 크기 예측은 영상 + 음성 비트레이트를 기준으로 합니다. 해상도/FPS만 바꾸고 비트레이트를 그대로 두면 용량 예측치는 동일합니다. 모바일 인코더는 요청 비트레이트와 실제 파일 크기가 달라질 수 있습니다.

저장 폴더 및 시작

가능하면 휴대폰 폴더 선택을 권장합니다. 지원되지 않으면 사이트 전용 저장소(OPFS)를 사용하세요. 두 방식 모두 기기 내부에 저장하며, OPFS는 사이트 데이터 삭제 시 영상이 사라질 수 있습니다.

저장 방식: 브라우저 내부 저장소(OPFS) · 사용 전 권한 검사 필요

녹화 준비 단계: 대기 중

장시간 녹화 주의: 전원에 연결하고 화면을 켜둔 채 Chrome 화면을 계속 표시하세요. 화면 잠금, 앱 전환, 배터리 절약 모드, 시스템 종료 시 녹화가 중단될 수 있으며 웹페이지로 이를 완전히 차단할 수 없습니다. 실제 30~60일 무중단 녹화는 보장하지 않습니다.

실행 안내

  • 이 HTML을 GitHub Pages 등에 게시하고 Chrome에서 https:// 웹주소로 열어야 합니다. 파일 앱에서 HTML을 직접 열면(content://) 보안·저장소 오류가 발생할 수 있습니다.
  • 첫 실행 시 카메라·마이크 권한을 허용합니다. 파일은 휴대폰에만 저장하며 서버로 영상을 전송하지 않습니다.
  • 모바일은 보통 WebM(또는 지원 시 MP4)으로 저장됩니다. MP4로 고정되지 않습니다.
  • 브라우저 삭제/사이트 데이터 삭제 시 내부 저장소의 파일이 삭제될 수 있습니다. 주기적으로 외부 저장소로 복사하세요.
  • 저장 주기는 근사치이며 분할 때 영상·음성에 짧은 공백이 발생할 수 있습니다. 실제 프레임과 비트레이트는 카메라/인코더에 따라 달라질 수 있습니다.
